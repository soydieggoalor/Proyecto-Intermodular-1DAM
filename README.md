# Proyecto Intermodular - 1º DAM
## IES Camp de Morvedre

Proyecto intermodular del primer curso de Desarrollo de Aplicaciones Multiplataforma (DAM).
Consiste en el diseño e implementación del Sistema de Información integral de una empresa,
incluyendo infraestructura, base de datos y software de gestión interna (ERP básico).
